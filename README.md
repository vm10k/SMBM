Super Mario Bros - Multiplayer Open World

Features:

-- Real-Time Multiplayer: Synchronized player positions, character animations, fireballs, and world interactions.
-- Two-Way Scrolling: Enhanced camera and physics engine allowing movement in both directions without losing floor collision or despawning map tiles.
-- Custom Character Options: Choose between Mario and Luigi with customizable retro outfit color palettes.
-- In-Game Proximity Chat: Real-time chat bubbles above player sprites and a dedicated chat log.
-- Live Global Leaderboard: Automatic high-score, coin, and completion tracking with paginated tables, column sorting, search filters, and disk persistence.
-- Touch Controls: On-screen tactile D-pad and action buttons with multi-touch sliding support for mobile and tablet browsers.
-- Responsive NES Scaling: Fixed 16:9 NES display logic with pixel-perfect scaling across mobile, 1080p, 2K, and 4K displays.
-- Solo Offline Mode: Option to play offline directly in the browser without connecting to a multiplayer room.
